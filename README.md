# IB Physics Retrieval Practice

Static retrieval-practice app aligned to the IB Physics guide for first assessment 2025.

- Separate SL and HL filtering
- All five themes and all 24 syllabus subtopics
- 1,000 original retrieval questions: 664 common/SL and 336 additional-HL or HL-only
- Exam-style contexts and wording informed by official IB specimen/sample papers
- Every question is self-contained; none depends on a missing diagram, graph or table
- Weighted retrieval based on student self-marking
- Random and daily quiz modes
- Wide, responsive topic selector for quicker subtopic selection
- Runs entirely in the browser; no login or server required

Open `index.html` locally or publish the folder with GitHub Pages.
